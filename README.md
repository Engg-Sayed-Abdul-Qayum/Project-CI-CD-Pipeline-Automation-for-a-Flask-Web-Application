End-to-end CI/CD pipeline project with GitHub, Jenkins, Docker, and Linux. Automated code integration, Docker image builds, webhook-triggered deployments, and application delivery.

# CI/CD Pipeline Automation

This project demonstrates an end-to-end CI/CD pipeline using GitHub, Jenkins, Docker, and Linux.

## Features
- Automated build and testing using Jenkins
- GitHub webhook integration
- Docker image creation on every commit
- Automated deployment to Linux server
- Consistent and repeatable application delivery

## Tech Stack
- GitHub
- Jenkins
- Docker
- Linux
